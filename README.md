# BriseTech (Planspiel Startup)

Official web placeholder for **BriseTech** (`BriseTech.net`).

> **Academic Project Notice**: This is an educational university student project for the **Web Engineering** (Planspiel) course at the **Technical University of Chemnitz** (**#myVSR**). It is not an actual commercial entity or live consumer product.

---

## 🛠 Tech Stack
- **Framework:** Next.js 14 (App Router)
- **Styling:** Tailwind CSS + Custom Design System
- **Animation:** Framer Motion
- **Icons:** Lucide React
- **Language:** TypeScript

---

## 🚀 Getting Started

To run the development server locally:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

To build for production:

```bash
npm run build
npm run start
```
